# data/user-needs/

This directory holds the structured raw material produced by `prompts/01-ethics-and-user-needs.md`. The files here feed into:

- Chapter 2 of the dissertation (user needs)
- Chapter 3 of the dissertation (ethical considerations)
- The UWE ethics form (submitted by the supervisor on Faith's behalf)
- The user testing protocol for the `regime-shap` package (Sprint 5, conditional)

## Files

| File | Purpose |
|------|---------|
| `ethics-reading-list.md` | Structured list of 6–8 ethics and XAI papers with engagement notes. All citations require manual Google Scholar verification before use. |
| `personas.md` | Four named user personas (two policy, two ML practitioner) with literature-evidenced needs. |
| `needs-design-mapping.md` | Narrative synthesis linking documented user needs to specific project design decisions. |
| `needs-design-mapping.csv` | Machine-readable version of the mapping for traceability. |
| `ethics-form-draft.md` | Draft responses to the UWE ethics form. Faith reviews, edits, and emails to supervisor. |
| `user-testing-protocol.md` | (Optional) Protocol for informal user testing of `regime-shap`. |
| `feedback-form-template.md` | (Optional) Feedback form for user testers. |
| `consent-template.md` | (Optional) Consent form for user testers. |
| `ethics_form_template.<ext>` | The blank UWE ethics form downloaded from Blackboard. Required input for `ethics-form-draft.md`. |

## Citation discipline

Every citation in any file in this directory must be manually verified against Google Scholar by Faith before any of this material appears in submitted work. Items not yet verified are tagged `[VERIFY]` next to the citation. This protocol is non-negotiable per UWE's Assessment Offences Policy and cannot be overridden by any AI usage override.

## Provenance

Files in this directory are drafts. Final report text is written by Faith in `report/chapters/`. Files here are referenced from the dissertation chapters and from `report/decision-log.md`; they are not submitted directly.
